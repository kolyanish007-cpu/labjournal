# Спецификация: Протоколы и снимки

Статус: утверждена. Реализация: milestone 1.

## Понятия

- **Шаблон протокола** (`protocols` + `protocol_versions`) — переиспользуемая
  инструкция (пошаговый markdown). Неизменяемая история версий: правка
  шаблона создаёт новую версию `version = max(version) + 1`, старые версии
  не удаляются.
- **Снимок** — при создании записи типа `experiment` из шаблона в `body_md`
  записи копируется полный текст выбранной версии протокола, а в начале
  записи добавляется служебный HTML-комментарий:
  `<!-- protocol: <protocol_id> version: <n> -->`. После создания записи
  снимок не обновляется никогда.

## Публичный API ядра

```python
def create_protocol(db, name: str) -> str: ...
def add_protocol_version(db, protocol_id: str, body_md: str) -> str: ...
def list_protocols(db) -> list[ProtocolSummary]: ...       # имя + последняя версия
def get_protocol_versions(db, protocol_id: str) -> list[ProtocolVersion]: ...
def start_experiment_from_protocol(db, protocol_id: str, version: int, title: str) -> str:
    """Создаёт запись experiment со снимком протокола. Возвращает entry_id."""
```

## UI

- Диалог «Протоколы»: список шаблонов, просмотр версий, создание/редактирование
  (редактирование = новая версия, поле ввода предзаполнено последней).
- Кнопка «Новый эксперимент из протокола» в главном окне: выбор шаблона и
  версии → открывается редактор новой записи с уже вставленным текстом.
- Выбор версии по умолчанию — последняя; выбор старой версии разрешён
  (повтор старого метода) и помечается в UI предупреждением.

## Критерии приёмки

- Правка шаблона не меняет `body_md` уже созданных экспериментов (тест).
- Служебный комментарий снимка парсится обратно: по записи можно узнать
  протокол и версию (тест).
- Удаление шаблона протокола в MVP не предусмотрено (только «архив» —
  флаг `archived INTEGER DEFAULT 0` в `protocols`, скрытие из списка выбора).
