# Спецификация: Экспорт в PDF и соответствие

Статус: утверждена. Реализация: milestone 1.

## Требования к экспорту одной записи

PDF-выгрузка записи должна выглядеть как страница лабораторного журнала:

1. Заголовок: название записи, тип, `created_at` (локальная время + UTC),
   `seq`, полный UUID.
2. Тело: markdown → HTML (`markdown` package, расширения `tables`,
   `fenced_code`) → `QTextDocument` → `QPrinter` (PDF). Картинки-вложения
   типа `image/*` вставляются в тело по маркерам `![name](attachment:<id>)`.
3. Блок «Целостность» внизу страницы: `hash` записи, `prev_hash`,
   список вложений с их SHA-256.
4. Колонтитул: `labjournal export — <дата экспорта>` и номер страницы.

## Публичный API ядра

```python
def export_entry_pdf(db, entry_id: str, dest: Path) -> Path: ...
def export_date_range_pdf(db, date_from: date, date_to: date, dest: Path) -> Path:
    """Записи периода одной пачкой — для сдачи журнала руководителю."""
```

Экспорт не изменяет БД (кроме чтения) и работает без GUI — только
`QPrinter`/`QTextDocument` допустимо вызывать с `QCoreApplication`
(offline-режим Qt), тесты UI помечаются `pytest-qt`.

## Дополнительные механизмы соответствия

- **Проверка целостности при старте** — `core.integrity.verify_chain()`
  (спека 02); результат — иконка статуса в строке состояния главного окна.
- **Бэкап** — диалог «Создать резервную копию» →
  `core.db.connection.backup_to()` (спека 01); кнопка «Проверить вложения» →
  `core.attachments.verify_attachments()` (спека 04).
- **Экспорт всего журнала в JSON** — `core.export.export_all_json(dest)`:
  полная выгрузка всех таблиц с хешами для внешней архивации.

## Критерии приёмки

- PDF содержит все обязательные блоки п.1–4 (тест: парсинг текста PDF
  не требуется, проверяется формирование HTML-документа и факт создания
  валидного PDF-файла с %PDF-заголовком).
- `export_all_json` воспроизводит состояние, из которого `verify_chain`
  проходит (тест на круговую проверку).
- Кирилический текст в PDF читаем (шрифт по умолчанию Qt, без встраивания
  кастомных шрифтов в MVP).
