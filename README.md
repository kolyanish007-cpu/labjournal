# labjournal

Локальный электронный лабораторный журнал (ELN) с приоритетом офлайн-работы:
неизменяемые записи экспериментов, шаблоны протоколов, вложения с контролем
целостности, полнотекстовый поиск и экспорт в PDF.

## Ключевые принципы

- **Локально прежде всего.** Все данные — в одной базе SQLite и папке вложений
  на вашем ПК. Никаких обязательных сетевых сервисов.
- **Неизменяемость записей.** Записи append-only: исправление — новая запись со
  ссылкой на старую. Каждая запись связана хеш-цепочкой (hash chain).
- **Протоколы как снимки.** Экспертимент фиксирует состояние протокола на момент
  проведения; правка шаблона не переписывает проведённые эксперименты.
- **Задел на рост.** Схема рассчитана на будущую многопользовательскую
  синхронизацию (UUID вместо автоинкрементов), но MVP — однопользовательский.

## Стек

- Python 3.11+
- PySide6 (Qt) — десктопный интерфейс
- SQLite + FTS5 — хранение и полнотекстовый поиск
- pytest, ruff — качество кода

## Запуск для разработки (Windows)

```powershell
git clone https://github.com/<ваш-логин>/labjournal.git
cd labjournal
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"
pytest
python -m labjournal
```
